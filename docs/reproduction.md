# Reproduction notes

This repository is a lightweight public snapshot of the AtomicNav project page. It contains the method description and figures, but not the executable training, evaluation, or runtime package.

## Future release

The complete code package will be added under [`code/`](../code/) when the release is ready. A full reproduction will additionally require a compatible RGB navigation environment, licensed scene data, model checkpoints, and the matching runtime configuration.

Before any public benchmark release, verify dataset and checkpoint licenses, pin the environment, document the observation and action protocol, and publish only traces and media whose terms permit redistribution.
