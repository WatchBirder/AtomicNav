# Demo materials

The investor demonstration is maintained outside this repository because it contains rendered simulator media and is not part of the reproducible code release. The intended demo compares a generic whole-route executor with AtomicNav on the same instruction and initial state, then shows the planner–executor handoff at atomic subgoals.

For a public release, include only media whose simulator and dataset terms allow redistribution. Do not commit raw benchmark frames, private service URLs, or API credentials.
